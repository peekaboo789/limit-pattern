# 涨停形态 iOS 客户端

连接 Docker 版（`ghcr.io/peekaboo789/limit-pattern`）的手机客户端，iOS 26 液态玻璃界面。本身不存数据、不算东西，所有功能都来自你的服务器。

## 安装（没有 Mac、没有付费开发者账号）

1. 打开 GitHub Actions 里的「Build iOS (unsigned IPA)」，进最新一次成功的运行，下载 `LimitPattern-unsigned-ipa`，解压得到 `LimitPattern-unsigned.ipa`。
2. 电脑装 [Sideloadly](https://sideloadly.io)，用数据线连上 iPhone（iOS 26 以上）。
3. 把 IPA 拖进 Sideloadly，填你的 Apple ID，点 Start。
4. 手机「设置 → 通用 → VPN 与设备管理」里信任这个开发者；iOS 16 以上还要打开「设置 → 隐私与安全性 → 开发者模式」。
5. 免费 Apple ID 签的 App **7 天后失效**，到期前用 Sideloadly 再装一次即可（数据都在服务器，重装后需重新登录；服务器列表和已保存账户存在本机）。

## 登录

- 登录页可添加、编辑、删除、切换多个服务器；地址允许 `http/https://主机[:端口]`，会自动去掉末尾 `/` 和 `/api`。
- 服务器地址：局域网填 `http://192.168.1.10:8000`（Docker 主机 IP + 映射端口）；外网填反向代理后的 `https://你的域名`。不写 `http://` 时默认加上。
- 账号、密码：0.5.1 起为管理员账号和密码；0.5.0 只有访问密码，账号留空。服务器没设密码时都留空直接登录。
- 登录成功会按服务器保存账户（敏感信息仅存 Keychain），下次轻点即可登录；会话过期会提示重输密码。
- 「更多 → 服务器与账户」里也可以切换服务器、管理账户、退出登录。
- 登录一次会一直记住，直到服务器改密码或「退出所有设备」。
- 第一次连局域网时 iOS 会问「允许查找本地网络设备」，要点允许。

## HTTPS / 局域网说明

- App 允许明文 HTTP，局域网直接用。走外网时请用 HTTPS（Nginx / Caddy / 群晖反代 + 证书），否则密码和 cookie 会明文传输。
- 自签证书 iOS 默认不信任，需要把证书装到手机并在「证书信任设置」里打开。

## 提醒

App 在前台或刚切到后台时轮询服务器，把榜单和自选股涨超 3% / 6% 发成本地通知（只在交易时段）。iOS 不允许后台常驻轮询，真正的后台推送需要付费账号的 APNs，所以锁屏提醒请用服务器的企业微信推送。

## 构建

`.github/workflows/ios.yml` 在 `macos-26`（Xcode 26.6，iOS 26.5 SDK）上用 XcodeGen 生成工程，跑单元测试，再以 `CODE_SIGNING_ALLOWED=NO` 编译并打包成未签名 IPA，同时用模拟器截图。接口约定见 `API_CONTRACT.md`。

相似度不是涨停概率，仅供复盘参考。

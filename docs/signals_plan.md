# 盘中信号模块 —— 深度方案（v0.6.0）

> 目标不是「多发提醒」，而是**证明每类信号是否真的有效**。核心交付物是可复现的
> 事件研究 / 显著性 / 校准报告，而不是又一个信号列表。
> 相似度 / AI 置信度都不是概率；本模块产出的所有「显著性」「超额收益」都是历史统计，不构成投资建议。

## 一、顶尖专家会做、但需求里没明说的事

1. **存「事件表」而不是「结果表」**：把每一条信号在发出那一刻的完整上下文（时点、快照、
   输入特征、模型版本、提示词版本、温度）落成一条不可变事件，事后只读、只补标签。验证永远
   在事件表上重放，而不是拿当天收盘后的聚合数回算 —— 这是杜绝未来函数的第一道闸。

2. **定义「基准收益」的口径并写死**：超额收益 = 个股收益 − 同期基准收益。A 股短线最常用的
   不是上证指数，而是**同市值分组的等权中位数**或**全市场等权**。专家会把基准也纳入快照
   （信号日当天全市场的收益分布），否则「超额」无从谈起。

3. **把「能不能成交」当成第一性约束，而不是事后减一个滑点**：T+1 意味着信号日买入、次日才能卖；
   一字涨停 / 开盘即涨停且封死到收盘的票，次日是买不进的，必须从「可成交样本」里剔除或单列。
   涨跌停价要用交易所口径按昨收四舍五入到分，ST/注册制/北交所各不一样，且要按信号日那天生效的规则算。

4. **多重检验校正不是可有可无**：一类信号下多个持有期（T+1~T+5）× 多个市场状态分组，天然会
   多重比较。专家一定做 BH / Holm 校正，并报告「校正后还有几条显著」。同时用**置换检验**给 p 值，
   因为超额收益分布不是正态。

5. **AI 置信度要做校准，而不是拿它当阈值**：可靠性曲线 + Brier 分数 + ECE。若 AI 说「置信 0.8」
   而历史上这种信号只有 40% 命中，要能指出来并自动降权 —— 这是「可验证」最硬的一块。

6. **滚动监控 + 自动退出的闭环**：上线不是终点。滚动胜率 / 超额收益跌破阈值要自动降权或停用，
   并把「某信号因为衰减被停用」本身也记成事件，形成证据链。

7. **诚实记录数据的边界**：免费源补不了历史 tick / 长历史分钟线。历史回测只能用日线 + 近期分钟线；
   shadow 模式往前进积累分钟样本。文档里必须明说「长历史分钟级回测不可得」，避免误导。

## 二、最原始的素材（按时间戳存快照，杜绝未来函数）

| 素材 | 粒度 | 用途 | 现状 |
|---|---|---|---|
| 分钟级行情（近期） | 1min OHLCV | 影子模式的信号时点、成交价 | 免费源只给近期分钟线 |
| 日线（未复权） | 日 OHLCV+额+换手 | 历史事件研究的收益、基准、分市场状态 | 已有 `daily_quotes`（sina/tencent/eastmoney 未复权） |
| 交易所涨跌停价 | 按昨收+板块规则现算 | 撮合不可成交、涨跌停判定 | 已有 `limit_up_service`（四舍五入到分、ST/注册制/北交所） |
| 停复牌表 | 代码+日期+状态 | 剔除停牌、判定可成交 | 缺，需从日线 volume<=0 / 无 bar 推导 |
| ST / 退市名单 | 代码+日期+状态 | 样本含 ST 和已退市股 | `Stock.is_st` 已有；退市名单缺失，需快照 |
| 除权除息表 | 代码+除权日+系数 | 未复权价格对齐收益 | 缺（未复权价 + 用前收算收益即可，除权日用前收而非昨收） |
| 已退市股票历史 | 日线 | 样本无幸存者偏差 | 免费源通常拿不到，需明确声明缺口 |

**关键原则**：所有输入在「信号日 15:00 后」先固化一份不可变快照（JSON 文件 + DB 行），验证只读快照。

## 三、具体方法与工具（不新增 pip 依赖，用已有 numpy/pandas/stdlib）

- **事件研究法**：对每类信号，计算信号日收盘买入、持有 T+1~T+5 的**累计收益**，减去同期基准
  （同板块/全市场等权中位数），得到超额收益；报告均值、中位数、t 统计量、胜率、盈亏比（平均盈利/平均亏损）。
- **置换检验**：把「信号 vs 非信号」的标签在样本内随机打乱 N 次（默认 1000），每次重算统计量，
  得到经验 p 值；不做参数假设。
- **多重检验校正**：BH（FDR）与 Holm（FWER）两条都算，输出校正后的显著性。
- **基准对比**：三类对照 —— 随机信号（同规模随机抽样的收益分布）、简单动量（前 N 日涨幅前 K 名）、
  等权全市场基准。
- **分市场状态**：按信号日情绪分组（涨停家数、炸板率、涨跌家数比、最高连板），每组的超额收益与样本量。
- **校准**：AI 置信度 → 分箱可靠性曲线、Brier 分数、期望校准误差（复用 `algorithms/calibration.py`）。
- **撮合/成本**：T+1、涨跌停不可成交、佣金（万 2.5 双边，最低 5 元）、印花税（卖出 0.05%，按现行）、
  滑点（如 0.1%）。
- **Walk-forward**：按时间滚动训练/评估窗口，报告样本外表现。
- **去重/冷却/时段门**：复用现有 `monitor_service.alert_phase` + `client.once`，信号只在交易时段、
  有冷却、有去重。

工具栈：numpy（统计/置换）、标准库 `random`/`statistics`（置换与分箱）、SQLite（快照与事件表）、
已有 `limit_up_service`（涨跌停价）、已有 `ai_client.chat` + `_extract_json`/`salvage_objects`
（AI JSON 解析，复用 0.5.4 的退避/截断救回）、已有 `ai_profiles`（模型切换，绝不硬编码密钥）。

## 四、除你我之外，什么能证明结果是对的

1. **可重放性**：每条信号有唯一 `signal_id` + 快照指纹；任何第三方用同一快照能重算出相同的
   收益与 p 值。输出里带「重放说明」（用了哪些表、哪些参数、哪个快照）。
2. **对账**：信号时点价格自动与第二数据源（腾讯/东方财富）对账，偏差超阈值标红；对不上就不进验证样本。
3. **交叉验证**：随机信号与简单动量两个对照组的实现和主信号同一套统计代码，若对照组也「显著」，
   说明方法本身有偏 —— 这是方法学上的自检。
4. **p 值 + 多重检验校正**：置换检验的 p 值 + BH/Holm，报告校正后还剩多少条，避免数据挖掘假阳性。
5. **样本外（walk-forward）+ 影子模式**：上线前 4~8 周只记录不提醒，样本外达标才开放推送，
   滚动监控持续验证 —— 时间本身是裁判。
6. **审计轨迹**：每类信号一条事件链（生成 → 影子 → 达标 → 上线 → 降权/停用），全部落库可查。
7. **单元测试**：无未来函数、T+1/涨跌停撮合、成本模型、置换检验、校准/Brier、冷却、时段门、
   AI JSON 解析，全部有测试（`tests/`）。

## 实现计划

### 数据层 `backend/app/services/signals/`
- `snapshot.py`：信号日快照（未复权日线 + 涨跌停价 + 停牌 + ST + 情绪分组），存文件 + DB。
- `tables.py`（并入 `models/tables.py`）：`SignalEvent`（事件表）、`SignalSnapshot`、`SignalOutcome`
  （T+1~T+5 标签）、`SignalShadowStatus`（影子/上线/降权/停用）。

### 信号层
- `rules.py`：规则信号（基于已有的相似度/涨停/量能特征，纯本地计算）。
- `ai_signal.py`：规则+AI 信号，固定提示词版本 + 温度，结构化 JSON，记模型版本（复用 `ai_client` +
  `ai_profiles` + `_extract_json`/`salvage_objects`）。

### 验证层（核心）
- `cost.py`：成本模型（佣金/印花税/滑点/最低佣金）。
- `fill.py`：撮合（T+1、涨跌停不可成交）。
- `event_study.py`：超额收益、胜率、盈亏比。
- `stats.py`：置换检验 + BH/Holm。
- `calibration_report.py`：可靠性曲线 + Brier（复用 `algorithms/calibration.py`）。
- `baseline.py`：随机信号、简单动量、等权基准。
- `walkforward.py`：滚动样本外。
- `market_state.py`：按情绪分组。

### 上线闭环
- `shadow.py`：影子模式（只记录不提醒，4~8 周）。
- `monitor_gate.py`：滚动胜率监控 + 自动降权/停用；去重/冷却，只走交易时段门。

### 对外
- API（`routes.py` / 新 `signals_routes.py`）：报告、事件列表、影子状态、重放。
- 企业微信指令：盯盘状态 / 最新信号 / 信号报告（`commands.py` + `notify.py`）。
- 前端 Vue3 页面 `SignalsView.vue`：有效性报告（收益分布、显著性、校准曲线、分市场状态）+ 声明。

# 企业微信自建应用

桌面版和 Docker 版都支持。设置 → 企业微信。

## 1. 在企业微信管理后台建应用

1. 登录 <https://work.weixin.qq.com/wework_admin>，应用管理 → 自建 → 创建应用，设置可见范围（要接收提醒的成员/部门）。
2. 记下：**企业ID**（我的企业 → 最下方）、应用的 **AgentId** 和 **Secret**（Secret 要在企业微信客户端里查看）。
3. **企业可信IP**（应用详情页底部）：把运行本系统那台机器的**公网出口 IP** 加进去。没加会报 `60020`。
   - 家用宽带 IP 会变，或桌面版不方便：在一台有固定 IP 的服务器上做个反向代理（把 `/cgi-bin/` 原样转发到 `https://qyapi.weixin.qq.com`），把它的 IP 加进可信 IP，再在设置的「接口地址 / 代理」里填这个代理地址。代理只影响**发出去**的请求。
4. 把上面的值填进设置，勾选要推送的事件，保存，点「发送测试消息」。

常见错误（页面会显示中文说明）：

| errcode | 含义 |
| --- | --- |
| 60020 | 出口 IP 不在企业可信IP → 加白名单或用代理 |
| 40001 | Secret 不对 |
| 40013 | 企业ID 不对 |
| 40056 / 301002 | AgentId 不对，或和 Secret 不是同一个应用 |
| 81013 | 接收人都无效 / 不在应用可见范围 |
| 45009 | 调用太频繁 |

## 2. 接收消息（在企业微信里发指令）

需要**公网 HTTPS** 地址，一般只有 Docker 部署在服务器上才有；桌面版通常只能推送，不能接收。

1. 应用详情 → 接收消息 → 设置API接收：
   - URL：`https://你的域名/api/wecom/callback`
   - 点「随机获取」生成 Token 和 EncodingAESKey，**先**把这两个值填到本系统设置里并保存，再回后台点保存（后台会立即 GET 验证 URL）。
2. 设置里的「指令白名单」填成员账号（通讯录里的「账号」，不是名字），逗号分隔。不在白名单的人发指令只会收到提示。
3. 指令：`榜单`、`自选`、`加自选 600519` / `加自选 茅台`、`删自选 X`、`采集`（盘中采集，回复前 10）、`总结`、`帮助`。

回调按官方 WXBizMsgCrypt 算法校验 `msg_signature`（SHA1）并用 AES-256-CBC 解密；回复走应用消息接口（异步，5 秒内先应答 success）。

## 3. 个人微信（微信插件）能看到什么

企业微信的「应用消息」里，`markdown`、`template_card` 只在企业微信客户端显示；通过 微信插件 / 微信互通 在**个人微信**里看会变成
「暂不支持此消息类型，请在企业微信中查看」（v0.5.0 默认用了 markdown，这就是原因）。v0.5.1 起默认 **文本**，个人微信能正常显示；
「卡片（textcard）」微信也能显示，但正文最多约 170 个汉字。Markdown 只建议纯企业微信客户端用户选。

底部菜单：在企业微信客户端的应用会话里一定显示。个人微信（微信插件）里是否显示菜单、能否点击，取决于企业微信对微信插件的支持，
本项目没法在真实账号上验证——如果你在微信里看不到菜单，直接发文字指令即可（菜单项都有同名文字指令）。
菜单点击和文字指令都要先配好下面第 2 节的「接收消息」回调，否则点了没有反应。

## 4. 底部菜单

设置 → 企业微信 → 「同步底部菜单到企业微信」（调用 `/cgi-bin/menu/create?agentid=…`，经过你配置的代理地址）。默认在新版本第一次启动时自动同步一次。

| 榜单 | 工具 | 自选 |
| --- | --- | --- |
| 今日AI榜单 | 一键采集+AI分析 | 自选行情 |
| 实时监控（榜单涨幅） | 切换AI | 自选异动≥3% |
| 相似前10 | 采集当前行情（前10） | 导出自选（文本） |
| 次日观察池 | 同步行情 | 系统状态 |
| 重新生成榜单 | 今日总结 | 帮助（含加/删自选用法、检查更新） |

- **一键采集+AI分析**：先回「⏳ 已开始」，后台采集当前行情 → 选前100 → 用当前 AI 模型打分出 AI 榜单（和网页「生成 AI 榜单」同一套），推前20 + 市场环境。非交易时段用最近一个交易日的数据并注明数据时间。同一时间只跑一个；没配好密钥 / 模型失败会发消息说明。
- **切换AI**：回复编号列表（✅=当前），5 分钟内直接回复数字就切换；超出范围会提示。只有白名单成员能用。
- 老版本菜单里的「添加说明 / 删除说明 / 检查更新」按钮仍然能点；重新同步菜单后换成新布局。

采集、同步、重新生成、相似前10、次日观察池 比较慢：先回「⏳ 已开始」，做完再推结果。
文字指令别名：榜单/AI榜单、监控、相似、观察池、重新生成、自选/自选行情、异动、加自选/添加自选、删自选/删除自选、导出自选、采集分析/一键采集/采集AI、切换AI/切换模型/模型/AI列表、采集、同步、总结、状态、检查更新/更新、帮助/菜单。
菜单同步报错：60011 无权限（应用可见范围要包含管理员 / Secret 不对应这个应用）、60020 IP 不在可信 IP。

## 5. 推送内容

- 盘中报警：AI 榜单和自选股涨幅 ≥3% / ≥6%，**只在交易时段**，每只股票每档每天最多一次（升档再推一次）。
- AI 榜单生成或导入、每日总结完成、日线同步失败、手动采集完成（前 10，可选）。

## 6. 群机器人（可选，更简单）

群聊 → 添加群机器人 → 复制 webhook 地址，填进「群机器人 webhook」。不需要可信IP，但不能接收指令。默认也发文本。

## 安全

Secret、Token、EncodingAESKey、webhook 只写入 `settings.json`，接口和页面只显示「已设置」，日志里也不会打印。

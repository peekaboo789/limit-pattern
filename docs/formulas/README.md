# 公式（v0.4.0 起）

本目录两份旧版导出文档是 v0.4.0 的实现依据：

- [ai_score_formula.md](ai_score_formula.md)：AI 打分公式（综合评分、三个分项、单股历史总分、预测分、档位统计）。原文逐字保存。
- [top100_selection.md](top100_selection.md)：每日「前 100 行」怎么挑（67 维向量、稳健缩放、欧氏+余弦、四个统计数、排序键、两段拼接、三道闸）。按原文整理保存（行号引用指向旧项目源码，本项目没有那些文件）。

## 与原文不同的地方（每一条都是有意的）

1. **样本池是近 N 个交易日（设置项，默认 30），不是 5 个。** 用户此前明确要求「改成近 30 日」，且设置页可改 3–60。原文的 5 日是旧项目常量。
2. **科创板（688/689）仍然剔除。** 本项目的纳入范围规则（`docs/rules.md`），原文全市场含科创板。
3. **缺失特征按样本池中位数补（标准化后为 0）。** 原文 §8 第 5 条自己指出旧代码「标准化前填 0」与 docstring「标准化后 0 即中位数」不符，这里按 docstring 的本意修正：缺数不表达偏离。
4. **新浪日线没有成交额 / 换手。** 成交额用「成交量 × 均价」估算（已有 `amount_estimated`），换手率用流通股本算；仍缺的按 3 补中位数。原文默认源同样整列为空。
5. **资金分恒为 None。** 和原文一致；成交额、换手虽部分有数，但不是资金流（主力 / 大单净额），不拿来冒充。
6. **样本池收尾在评估日（含评估日当天收盘的涨停）。** 原文基准日是「严格早于今天的最近一个有涨停样本的日子」，那是盘中榜的口径；本项目同时服务盘后，盘中临时线（`intraday` / `morning_freeze`）上的「涨停」不进样本池，所以盘中效果与原文一致。
7. **上市满 20 个完整交易日的判定。** 有上市日期就用上市日期；没有时数库里完整 K 线（半天线不算）。如果这只股票的第一根 K 线就在库里最早的日期，视为历史被保留期截断而不是新股，按已满 20 日处理（库只保留约 40 个交易日）。
8. **原文只给了特征名的地方按名字补全了定义**：`*_change` 为相对前收的百分数，`body_length = |收−开| / 前收 × 100`，影线同理，`volume_ratio_5/10` = 当日量 / 前 5/10 日均量，`position_n` = 收盘在近 n 日高低区间的位置（0~1），三个趋势字段编码为 +1 / −1 / 0（三天单调升 / 单调降 / 其余）。
9. **历史成功率（history_limit_up_rate）**：该股高度相似（≥ 阈值）且已定判的样本中，样本「涨停次日继续涨停」的比例 × 100。次日晚于评估日或库里没有的样本不进分母（不看未来）。没有已定判的高度相似样本时为 None，权重摊给其余项。
10. **档位倍率的基准**：回测期内全部候选（不只前 100）的次日涨停率。原文写的是 `run.baseline_rate`，没给定义。
11. **单股历史总分的数据源**：本项目没有 `ai_pick_results` 表，用已保存的每日最终榜（每个交易日最后一次运行）里该股的模型分（没有模型分时用当时的 `ai_score`）和次日正式日线对账。
12. **七组分（group_scores）只做展示**：同一标准化、同一距离尺度、按组权重开方还原后的组内欧氏分，不参加总分。
13. **前 20 怎么来**：在线生成时从前 100 里按系统综合评分取前 20（同分按最高相似度、代码）；外部导入时保留外部挑的代码，但按系统综合评分重新排序，外部 score 记为模型分并显示偏差。AI 失败或没配 AI 时照样按综合评分出榜，只是没有模型依据。
14. **position_60 受保留天数限制。** 库里默认只存约 40 个交易日，`position_60` 按已有天数算（导出里写成「位60(40日)」）。真实数据核对时，600132 的技术分因此是 64.9（用 40 日区间）而按新浪 60 日算是 60.6；其余分项与按新浪原始 K 线手算完全一致。需要严格 60 日时把设置里的保留天数调到 ≥ 62。
15. **body_percent** 按「实体 / 当日振幅 × 100」现算（原文是库里已落好的百分数列，本项目没有该列）。

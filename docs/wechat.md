# 个人微信（iLink Bot / ClawBot）

桌面版和 Docker 版都支持。设置 → 个人微信。这个渠道**不需要公网回调**，适合桌面版：程序直接轮询 iLink 网关收发消息；另一个「企业微信」渠道才需要公网 HTTPS 回调。

## 1. 先理解它适合干什么

- 推送：盘中报警、AI 榜单、每日总结、日线同步失败、手动采集完成。
- 收指令：在个人微信里直接给机器人发 `榜单 / 自选 / 加自选 X / 删自选 X / 采集 / 总结 / 帮助`，由程序每 15 秒轮询后回复。
- 只发纯文本：标题 + 正文合并，超过约 1800 字自动分段；不依赖企业微信的卡片/Markdown 格式。

限制：
- 走的是 iLink Bot / ClawBot 的网关协议（默认 `https://ilinkai.weixin.qq.com`，可换成你自己的同形状网关）。如果该网关对个人号登录 / 消息频率有限制，以你实际使用的网关为准。
- 扫码登录后，token / context 只存在内存和 `data/wechat_session.json`，页面和接口都不回显；日志不打印 token。
- 与「企业微信」是两条独立渠道：同一事件会分别去重、可同时收到；指令只从收到的那个渠道回复给发消息的人。

## 2. 设置步骤

1. 打开页面：设置 → 个人微信。
2. 勾选「启用个人微信推送」；确认「接口地址」保持默认 `https://ilinkai.weixin.qq.com`，如果你有自托管网关就改成它的地址。
3. 不需要再填白名单：扫码登录后，用你自己的微信给机器人发任意一条消息，第一个发送者会自动绑定为管理员；之后只有管理员能发指令和接收主动推送，其他人的消息会被忽略。
4. 勾选要推送的事件，保存。
5. 点「获取二维码」，用**要作为机器人的个人微信**扫码。
6. 页面显示「扫码登录成功，已保存会话到 ./data」后，点「发送测试消息」，在同一个微信号里应收到 `✅ 涨停形态系统 测试消息`。

如果扫码后状态一直是未登录，请检查：`wechat_api_base` 是否能从本机访问、当前网关是否支持该接口形状（`get_bot_qrcode` / `get_qrcode_status` / `getupdates` / `sendmessage`）。

## 3. 可发送指令

白名单内用户发给机器人即可，和网页/企业微信共用同一套命令：

`榜单`、`自选`、`加自选 600519` 或 `加自选 茅台`、`删自选 X`、`采集`、`总结`、`帮助`。

程序每 15 秒拉一次新消息；因此回复不是即时推送，通常有最多 15 秒延迟。

## 安全

- `wechat_token` 只写入 `settings.json`，页面与 `/api/settings` 只显示 `wechat_token_set`。
- 扫码得到的会话 token 和绑定管理员的 `ilink_user_id` 写 `data/wechat_session.json`；该文件和 `settings.json` 都含敏感信息，备份时请妥善保管。
- 主动推送需要管理员先给机器人发过一条消息：程序用对方最近的 `context_token` 才能回复，发过消息后 token 会保存在会话文件里。如果推送提示登录失效/无 context，请重新扫码并再发一次「帮助」。

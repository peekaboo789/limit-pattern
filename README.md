# 三日涨停形态统计系统

看沪深 A 股里，最近涨停的股票在涨停前三天怎么走，再拿其它股票最近三天的走势去比，给出 0 到 100 的形态相似度。

## 核心规则

- 相似度不是涨停概率，也不构成投资建议。
- 只用行情，不用新闻、公告、财报。
- 不算未来的数据。样本看涨停之前的三天，被比较的股票才包含当天。
- 行情和涨停标签默认只留最近 5 个交易日，到点自动删除。天数可在设置里改。
- 每个交易日的 AI 总结 JSON 单独保存，不参与上面的删除。
- 相似度只和最近 3 个交易日内涨停过的股票比，并且排除自己。
- 只做上证 A 股和深证 A 股。

规则的具体算法见 [docs/rules.md](docs/rules.md)。

## 这一版能做什么

- 从东方财富同步沪深 A 股日线，并给涨停打标签。
- 查看某一天的涨停，以及最近三个交易日的涨停池。
- 看全市场相似度排行，或查询单只股票最像哪些涨停样本（含 K 线、成交量、成交量百分比）。
- 收盘同步完成后写当天总结。没填 AI 时先存统计（数量、板块、连板、量能）；配了再补解读。
- 库是空的会自动开始第一次同步。进度在 `/api/sync/status`。
- 在设置里改明细保留天数、数据源和 AI 地址 / 模型 / 密钥。密钥只保存，接口不回显。

## 快速开始

### Windows 桌面程序

打包在单独的流程里完成。双击 `LimitPattern.exe` 后会打开窗口，数据在本机目录（见下面的配置表）。

### 源码

```bash
pip install -r requirements.txt
python -m backend.app.main
```

浏览器打开 http://127.0.0.1:8765 。若先构建了前端，把产物放在 `frontend/dist`，同一个端口会带上页面。

### Docker

这一版还没有镜像。请先用源码或 Windows 程序。

## 配置

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 端口 | `127.0.0.1:8765` | 只在启动命令里改 |
| `LP_DATA_DIR` | Windows：`%LOCALAPPDATA%\LimitPattern`；其它：`~/.limit_pattern` | 数据库 `lp.db`、设置、`summaries/` |
| `LP_STATIC_DIR` | 仓库里的 `frontend/dist` | 有这个目录才挂网页 |
| `LP_SCHEDULER` | 开启 | 设为 `0` 关闭 17:10 同步和 17:40 清理 |
| 保留交易日 | 5（可改 3–30） | 设置页 |
| 对比交易日 | 3 | 固定，不能改 |
| 数据源 | `eastmoney` | 这一版只会拉东方财富 |
| AI 地址 / 模型 / 密钥 | 空 | 设置页填写。空着则总结功能未启用 |

复制 `.env.example` 不是必须的。上面几项用环境变量或设置页即可。
